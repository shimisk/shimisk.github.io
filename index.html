Install The Apps

First, open each app in your browser and test it. If you like it, install it to your home screen or desktop for quick access.

Android (Chrome/Edge)

  1. Open Sudoku or Valheim Companion from the banners below and try it in-browser.
  2. Tap the browser menu (⋮).
  3. Tap Install app or Add to Home screen.

iPhone/iPad (Safari)

  1. Open the app page in Safari and test it normally in the browser.
  2. Tap the Share button.
  3. Choose Add to Home Screen.

Desktop (Chrome/Edge)

  1. Open the app page from this storefront and test it in the browser first.
  2. Click the install icon in the address bar.
  3. Confirm with Install.
